## About me

Engineering student in computer science and embedded systems at ENSSAT (Université de Rennes),
Lannion, France. I like building things end to end, from a board designed in EAGLE to a Flask
server on a Raspberry Pi.

- Based in Lannion, France
- Speaks French, English and Arabic
- Open to internships and collaborations
