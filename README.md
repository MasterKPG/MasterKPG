### Selected projects

- **[Solibox](https://masterkpg.github.io/#project-solibox)**: an offline education server on a
  Raspberry Pi for the non-profit Togo Vert et Vivant Trégor. Its own WiFi, a captive portal,
  PDFs, quizzes, an offline Wikipedia and videos, no internet needed. Won the 2026 PIEED award.
- **[Smart Garden](https://masterkpg.github.io/#project-smart-garden)**: an LPC1768
  (ARM Cortex-M3) plant monitor with four sensors, thresholds, an alarm, an LCD and a
  password-protected Bluetooth interface.
- **[Saturating Accumulator on FPGA](https://masterkpg.github.io/#project-saturating-accumulator)**:
  VHDL, verified in simulation and on a DE10-Lite board.
- **[Arduino Uno Clone](https://masterkpg.github.io/#project-arduino-clone)**: designed in EAGLE,
  from schematic and routing to soldering and bootloader.
- **[Parking Simulator](https://github.com/MasterKPG/prog_sys_project)**: a car park simulator in
  C using Linux IPC (FIFOs, shared memory, semaphores).
